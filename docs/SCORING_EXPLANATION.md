# 评分及解释规则

## 适用范围

此项目的四个维度名称与四字母格式仅用于简短的自我探索。当前 12 题没有公开的抽样、信度、效度或重测证据；不能宣称为官方授权 MBTI，也不能把本次结果用于医疗、招聘或能力判断。

## 计算

- 每维度 3 道题，每题恰好一个选项。
- 每个选项的方向为 E/I、S/N、T/F、J/P 中的一侧，权重取 1 或 2。
- `evaluateAnswers` 将同一维度两侧权重累计，比较左右得分。
- 严格大于时选择对应方向，左右相等时记为 `null`，不强制归类。
- 未完成全部 12 道题时，`type=null`。
- `explainAssessment` 返回所有维度的原题 ID、所选选项、计分权重、选择次数和中性文本解释。

## 证据

用户在结果页展开某维度，可见该维度三道题的标题及个人选项。证据数据在浏览器本地即时计算，不上传服务端。结果展示的是**问题选择次数**与文本解释，不把选项权重比例冒充人格强度。

## 版本契约

- app version V2.2：UI/构建/数据治理升级。
- bank version 2.1.0：题库 ID、文本与原选项意义保持不变。
- scoring version 2.1.0：累加方向和权重规则未变。
- interpretation version 2.2.0：引入答题证据与中性措辞。

若未来题库或算法变更，必须给出兼容性评估及迁移测试，不能静默复用历史记录。

## 禁止的产品文案

不得宣称人格概率、心理诊断、预测能力、百分百准确、信度得分、职业适配准确率等；文案必须使用“本次情境中”“依本问卷规则”等限定语。
