# V2.2 无障碍验收与人工测试清单

目标参考 WCAG 2.2 A/AA，并记录所有尚未人工核验的条目，不以自动扫描通过等同于完全符合规范。

## 已纳入代码

- 答题选项改用 `fieldset` + 原生 `input[type=radio]` + `label`，确保互斥关系、方向键与空格语义。
- 上一题 / 下一题以及访问其他屏幕时，页面标题可被程序聚焦；禁用尚未作答的下一题。
- `aria-valuenow` 表示已回答题数，而非当前所在题号；读屏提供已完成 X / 12。
- 提高弱对比文字及装饰性代码字母对比度；使用 `:focus-visible` 和 `forced-colors`。
- `prefers-reduced-motion` 与移动端响应式布局继承 V2.1 实现。
- axe-core/Playwright 覆盖首屏、问卷、图鉴；结果页应另行验证并补充人工走查。

## 需要人工执行的项目

- NVDA + Chrome：导航、原生 Radio、所选项、结果证据展开、提示朗读。
- VoiceOver + Safari：Tab、标题焦点、单选切换与结果页面。
- TalkBack + Android Chrome：触摸探索、选项切换、提交、清除本地数据。
- 200% / 400% 缩放：标题和卡片不遮挡、不裁切、不出现妨碍完成任务的水平滚动。
- Forced colors / Windows High Contrast：单选选中、焦点与进度具有可辨认状态。
- 低运动模式：没有依赖动画表达的必要信息。
- 屏幕阅读器公告：答题选中、切题、结果生成不应重复朗读或无响应。
- 图片 alt：仅描述趣味角色，不声称能够从插画推断人的心理属性。

**尚未执行以上人工测试前，不要对外宣称全站通过 WCAG 2.2 AA 认证。**
