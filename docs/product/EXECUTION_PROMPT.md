# 高标准实现提示词（V3.0）

以下是为新一轮工程任务准备的提示词；不代表已经实现。

目标：在 https://github.com/1998x-stack/MBTI 的当前 main 基线上，将 PersonaQuest 改造成“能展示推断依据、允许用户反驳、默认本地保存”的可解释情境人格探索产品。请先阅读 docs/product/PRD_V3_0.md、PH_HN_RESEARCH_2026.md、VALIDATION_PROTOCOL.md 和 PRODUCT_HUNT_LAUNCH.md。

优先实现 V3 P0，而不是一次性搭大平台：首先开发无需注册的一题可交互 Demo（严格不参与真正测评）；再用纯函数反事实模拟器试算修改某一道题后的确切分数及四轴差异，确保无论如何都不改动传入原答案或 localStorage，只有明确提交才保存；之后区分四轴加权分数与选择次数。

保留 V2.2 题库、16 类型、平局规则、数据契约和历史分支。不要增加 LLM 教练、官方 MBTI 认证、关系匹配打分、账户系统或上传原始答案的追踪。为所有变更编写 Node 黄金测试、Playwright 桌面/移动测试及 axe 无障碍检查；记录没有执行的真实读屏/用户实验。

产品目标：真正测试者在 90 秒内理解结论如何形成；至少 80% 测试者能清楚描述“结果只是选项的汇总，不是心理诊断或概率”。这些是实验阈值而非现有成果。外部裁判为 CI、可重复的浏览器测试和经同意的独立真人任务实验；达不到标准就报告失败、修正，不虚构分数。

每个阶段在新 feature 分支实现并 self-review、完成实际验收，提交独立且可审查的 PR。不要擅自将文档中的假设写成已验证事实，不要擅自修改历史版本分支或在不成熟时提交 Product Hunt。
