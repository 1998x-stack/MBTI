# PersonaQuest · V3.0 产品战略与外部研究

当前仓库 V2.2 已具有十二道原创题、可解释评分、16 角色、隐私优先的本地存储和 GitHub Pages。V3 的“单题演示、反事实、反思批注、英文完整体验、分享卡”是**规划，不是已经完成的功能**。

推荐顺序：

1. [PH/HN 外部用户证据台账](./PH_HN_RESEARCH_2026.md) — 来源、异议、样本局限、需要证伪的假设。
2. [V3.0 PRD](./PRD_V3_0.md) — 产品主张、用户旅程、UX 与代码文件级需求、优先级和验收。
3. [独立用户验证协议](./VALIDATION_PROTOCOL.md) — 真实参与者的任务、观察、Go/Iterate/Stop 门槛。
4. [Product Hunt 作战文档](./PRODUCT_HUNT_LAUNCH.md) — 定位、英文素材、合法发布流程和 Go/No-Go。
5. [高标准执行提示词](./EXECUTION_PROMPT.md) — 将本目录直接交付工程执行。

本次任务的核心标准：**更好的用户价值，而不是更多功能**。结果由真实体验与独立测试裁判判定，不能凭模型或开发者自评。

已存在的发布硬化 PR #3：https://github.com/1998x-stack/MBTI/pull/3 。本设计文档独立，不代替 PR #3，亦不会修改历史版本快照。
