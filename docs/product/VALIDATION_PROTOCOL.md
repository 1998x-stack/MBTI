# PersonaQuest V3.0 — 独立用户验证与实验协议

状态：拟执行，尚未开展真人测试。目的：让产品价值接受独立用户而不是开发者或 AI 自评。日期：2026-11-03。

## 1. 需要被证伪的核心假设

相较于 V2.2 的标准 12 题→趣味画像路径，V3.0 的一分钟可交互解释示例与结果反事实模拟，会使用户更容易理解：分类只是原始答案和评分规则的可检查结果，不是对人格或能力的确定测量。

最强的检验不是按钮点击次数，而是用户能否独立找到证据，并准确说明“改变某一道题会影响哪个维度，以及结果不等于人格概率”。

## 2. 参与者与数据最小化

- 第一轮邀请 12–20 名自愿参与者，覆盖第一次接触性格分类与有相关经验者、手机和桌面用户、愿意参加的辅助技术使用者。
- 不要求展示真实人格类型、健康信息、聊天记录、私人笔记、联系人或其他与任务无关的数据。
- 说明可随时停止，并非为了获得产品使用资格而必须参与。录像、截图与引用反馈均需分别同意；未同意时只记录匿名任务层面统计。
- 每位参与者只使用随机编号；不对外公开答题明细。样本很小，不能得出统计显著性或普遍市场偏好的结论。

## 3. 对照测试设计

方案 A：现有 V2.2，直接完成十二题、读取画像并查看三条维度证据。

方案 B：V3 原型，先体验独立的一题示例、切换答案观察解释变化、再做十二题、使用反事实工具并选择“符合/不符合/看情境”。

两版交叉随机 AB / BA，记录顺序、设备和浏览器。两版均保持无注册。主持人不得提示按钮位置、正确答案或正确评价。

## 4. 标准任务、判定与目标

| 任务 | 可观察行为 | 假设通过门槛 |
| --- | --- | --- |
| T1 初见定位 | 15 秒内说出它与一般人格测评的区别 | ≥60% 能明确提到证据或质疑 |
| T2 首次价值 | 不求助、90 秒内找到互动演示并切换答案 | ≥70% 成功 |
| T3 正式测评 | 完成十二题、返回修改、刷新恢复 | ≥85% 完成，且无答案丢失 |
| T4 解释理解 | 找出影响同一维度的三题，区分题目数量与加权分数 | ≥80% 理解；不误认为人格概率 |
| T5 反事实 | 切换一道题并撤销，解释正式保存与沙盒的区别 | ≥90% 正确 |
| T6 个人反思 | 能选择“符合/不符合/看情境”并可删除本地信息 | 无阻断、无强制输入 |
| T7 隐私分享 | 能预览分享卡并说明它不包含哪些个人内容 | ≥90% 说对 |
| T8 无障碍 | 只用键盘、实际读屏可完成相同关键任务 | 不允许 P0 阻断 |

以上阈值是**设计决策阈值**，不是已有成果；在少量参与者中，需同时保留原始任务失败原因，不能使用小样本精确估计市场占有率。

## 5. 主持人不诱导的提问

- 你认为刚刚这几个字母说明什么？又不能说明什么？
- 如果你不同意某一句，你会在哪里验证？
- 切换一个选择时，你原先的作答会被更改吗？
- 你会愿意公开分享什么？什么内容只留在设备上？
- 哪一步最容易让你误解、迷路或中途放弃？
- 如果只保留一个功能，你会保留什么？为什么？

不问“这个测评是不是很准确”“你是不是很喜欢我们新功能”等诱导性问题。

## 6. 最小观察记录

匿名 participant_code、版本 A/B、设备、task_id、完成与否、帮助次数、完成秒数、误解类别、真实错误描述、修复 issue 链接。不得保存个人自由反思文本、私人答案或具体画像。录像等附加数据只在明确同意之后使用。

依赖自动化测试的检查：每道题四选项反事实黄金测试、不可变原答案与 localStorage、平局、跨语言 id 一致性、私有笔记导出与删除、320px/400% 放大、forced colors、reduced motion、浏览器 Page errors、GitHub Pages HTTPS 实际静态资源响应。

真正的 NVDA、VoiceOver、TalkBack 体验须记录真实测试设备、执行人及结果，不得因为 axe 测试通过就声称已完成真人 WCAG 认证。

## 7. Go / Iterate / Stop 判定

Go：独立理解、隐私、体验与 P0 自动测试达到目标，重要问题修复且上线页面与宣传完全一致。

Iterate：用户说不清准确率与证据的区别，或在首次 90 秒体验中不理解怎么操作。优先改入口和示例，而不是追加 AI 报告、类型或提醒。

Stop：分享泄露逐题回答/笔记；产品暗示真实临床或就业判断；测评导致持久的不公平标签；严重无障碍阻断；或者主要用户根本不觉得解释过程有价值。

## 8. 独立验证报告模板

记录：日期、版本、commit SHA、可访问的网址、测试方法与参与人数、不同顺序的任务成功数/总数、耗时中位数、显著误解案例、匿名反馈、未解决 P0/次级问题、人工读屏检查结果、性能工具及环境。

结论必须拆为：已观察事实、团队解释、可替代解释、未获得证据、下一次实验。**目前这些用户数据均未收集。**
